    The rules every path keeps

    From the security design doc, Appendix A.

    I-24 · Unconfirmed never acts

    Group-suggested rules decide nothing until the patient confirms them; while sharing is off, every request asks.

    I-28 · Key-bound tokens

    Every token is bound to the requester's key and stored only as a hash. Bearer tokens are refused.

    I-29 · Declines look alike

    A rule's decline and a person's are the same answer; ignoring looks exactly like no answer yet.

    I-30 · One door

    Direct, group or member: every request is a signed GNAP request, decided by the patient's own cards.

    I-31 · One exit

    Data leaves only from the resource server. No email, relay message or log carries health data.

    I-33 · Asks only when told

    A MAIA sends a request for its user only after they click Send. Planned more widely in P11.
