MAIA Group Network

Four MAIA servers: two host patients' MAIAs, and two host only a group, one of them run by an oncology practice. A radiologist with no MAIA and no group sends a report. Only the major links are drawn: the request, and the resource access.

The MAIA Request Map shows each request step by step, from every perspective.

Request: a signed GNAP grant request Request carried by a group: a signed copy, sealed to the member Resource access: a key-bound token at the patient's resource server AS decides with the patient's rules · RS is the only exit for data · Client asks for the patient

Group hosts are ordinary MAIA servers that host only a group: they never decide a request and can't read an answer, which travels back sealed to the requester (not drawn). A host can also run patients' MAIAs and a group at once. Tags on each patient show their group memberships; the lines show only what happens in these three examples.
